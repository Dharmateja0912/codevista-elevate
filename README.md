# CodeVista Academy Hub

Build a complete, modern, premium, responsive Computer Training Institute website called "CodeVista Academy".

TAGLINE:

"Learn Today. Build Tomorrow."

The website should look like a professional real-world IT training institute, not a basic college project.

The institute provides practical computer and technology training for students, graduates, and professionals.

The website should allow visitors to:

- Explore technical courses

- View detailed course curriculum

- Explore trainers

- View upcoming batches

- Reserve a seat

- Learn about certifications

- Explore placement assistance

- Submit course registration

- Contact the institute

- Optionally access a student learning dashboard

IMPORTANT:

This is primarily a FRONTEND project.

Use realistic mock data.

Use React state and localStorage for frontend interactions where a backend is not required.

Do not create empty pages.

Do not create fake buttons that do nothing.

All important buttons should have a visible interaction such as navigation, modal, toast, filtering, form submission, or state update.
